# Capturas do PHP IDE

Imagens de 24/10/2026, da interface atual (PHP IDE 0.2.14):

- `php-completion.png`: autocomplete de métodos em `App.php`, com tipos de retorno.
- `php-navigation.png`: `Named.php` aberto, árvore do projeto e painel do agente.
- `database.png`: editor, painel Database e grade da tabela `customers`.

Foram renderizadas no frontend atual, em viewport 1440×908 (2880×1816), com os workbenches fixados de Git, Agents, Database e PHP Intelligence. O macOS não permitiu fotografar a janela nativa. O projeto `pedidos` e as linhas de `customers` são sintéticos (`example.invalid`). A barra de sugestões SQL, que o plugin de banco mostra acima de arquivos PHP, ficou oculta nestes três quadros para o editor, o autocomplete, o agente e a grade permanecerem legíveis.

São registros da nossa interface, não uma garantia da aparência de cada release. Não são capturas do PhpStorm. Nenhuma captura de referência proprietária foi incorporada. Os dados mostrados são de teste; estas imagens não comprovam compatibilidade funcional.
